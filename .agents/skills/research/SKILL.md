---
name: GraphFlow Knowledge Pipeline Skill
description: Research a topic, extract concepts, organize Obsidian note hierarchy, generate graph-connected documentation.
---

# Pattern

`[fetch] [think/reasoning] [organize]. [next_step]`

Example:

```text id="nrmxsr"
[Fetch] Collect multiple sources about Cognitive Bias.
[Think] Identify major concepts, mechanisms, and relationships.
[Organize] Create atomic notes and graph links for Obsidian.
[Next Step] Generate markdown files and related topics.
```

---

# Flow

Follow this pipeline:

```text id="apf2jt"
1. Fetch Web Sources
2. Extract Knowledge
3. Normalize Concepts
4. Organize Knowledge Hierarchy
5. Generate Obsidian Files
6. Link Related Notes
```

Never generate notes before web research.

---

# 1. Fetch Web Sources

[Fetch] Search internet first using multiple reliable sources.  
[Think] Compare explanations, terminology, examples.  
[Organize] Extract reusable knowledge blocks.  
[Next Step] Normalize concepts and relationships.

Collect:

* definitions
* concepts
* mechanisms
* examples
* applications
* history
* references
* related topics

Prefer:

* official sources
* academic papers
* textbooks
* educational resources
* expert materials

Avoid:

* low-quality summaries
* unsupported claims
* duplicated content

---

# 2. Extract Knowledge

[Fetch] Gather detailed information from researched sources.  
[Think] Identify core ideas, mechanisms, workflows, relationships.  
[Organize] Convert information into atomic reusable notes.  
[Next Step] Build concept hierarchy.

Extract:

* overview
* terminology
* core concepts
* mechanisms
* examples
* edge cases
* applications
* limitations
* comparisons
* advanced topics
* references

---

# 3. Normalize Concepts

[Fetch] Collect related concepts and terminology variations.  
[Think] Remove duplicates, identify canonical naming.  
[Organize] Create parent-child and adjacent relationships.  
[Next Step] Build folder hierarchy.

Example:

```text id="2g79bb"
Psychology
├── Cognitive Bias
├── Memory
└── Decision Making
```

---

# 4. Organize Knowledge Hierarchy

[Fetch] Identify concept groupings and hierarchy from research.  
[Think] Determine logical structure and graph relationships.  
[Organize] Create folders, subfolders, atomic note structure.  
[Next Step] Generate markdown files.

Example:

```text id="xtjlwm"
Knowledge/
└── Psychology/
    └── Cognitive Bias/
        ├── overview.md
        ├── references.md
        ├── related.md
        ├── core_concepts/
        ├── mechanisms/
        ├── examples/
        ├── applications/
        ├── history/
        ├── comparisons/
        └── advanced/
```

Rules:

* one concept per file
* avoid giant notes
* maximize graph links
* support scalable vault growth

---

# 5. Generate Obsidian Files

[Fetch] Use extracted and normalized knowledge.  
[Think] Determine reusable note boundaries and graph connectivity.  
[Organize] Generate markdown notes for Obsidian.  
[Next Step] Link related notes.

## overview.md

```md id="sxjlwm"
# Cognitive Bias

Systematic patterns of irrational judgment affecting decision making.
```

## core_concepts/

```text id="hyxmbx"
core_concepts/
├── confirmation_bias.md
├── anchoring_bias.md
└── survivorship_bias.md
```

Atomic note example:

```md id="r3c7iw"
# Confirmation Bias

## Overview

Tendency to favor information confirming existing beliefs.

## Mechanism

Selective attention toward supporting evidence.

## Examples

- political media consumption
- investing decisions

## Related Topics

- [[Cognitive Bias]]
- [[Decision Making]]
```

---

# 6. Link Related Notes

[Fetch] Identify adjacent and interdisciplinary concepts.  
[Think] Determine graph relationships and backlinks.  
[Organize] Connect notes using Obsidian links.  
[Next Step] Expand graph recursively when needed.

Example:

```md id="mfv8r9"
[[Psychology]]
[[Decision Making]]
[[Behavioral Economics]]
```

Avoid isolated notes. Maximize backlink density, graph connectivity, knowledge discoverability.

---

# Output Requirements

Generate:

1. folder hierarchy
2. markdown files
3. atomic notes
4. graph links
5. references
6. related topics
7. interdisciplinary connections

---

# Goal

Generate deep research knowledge systems, graph-connected Obsidian notes, reusable atomic knowledge, scalable learning vaults, interdisciplinary knowledge graphs, long-term reusable knowledge.
