# cheat

> Cheat allows you to create and view interactive cheatsheets.
> More information: https://github.com

- View the cheatsheet for a specific command:
  cheat {{command}}

- Edit your personal cheatsheet for a specific command:
  cheat -e {{command}}

- List all available cheatsheets:
  cheat -l

- Search available cheatsheets for a specific keyword:
  cheat -s {{keyword}}
